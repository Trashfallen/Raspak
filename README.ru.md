# Raspak

[English version](README.md)

Архиватор для Windows: маленькое окно, меню проводника, один exe на Go без установки.

## Возможности

- **Форматы.** zip, 7z, rar (в том числе многотомные `.part1.rar`), tar, tar.gz/.bz2/.xz/.zst/.lz4, одиночные `.gz`, `.xz`, `.bz2`, `.zst`, `.lz4`, `.br`, `.lz`, тома `.001`, `.002`... (разбиение 7-Zip и Total Commander).
- **Пароли.** zip (ZipCrypto и AES), 7z (в том числе со скрытым списком файлов), rar.
- **Русские имена** в zip из старых архиваторов (cp866).
- **Окно.** Перетащить архив, походить по папкам, открыть файл двойным кликом, распаковать все или выбранное, проверить архив. Файлы можно вытащить из окна в проводник, на рабочий стол или в другую программу.
- **Умная распаковка.** Если в архиве одна папка, она кладется рядом с архивом как есть, иначе все уходит в папку с именем архива. Имена не перезаписываются (`x (2)`).
- **Меню проводника.** «Распаковать здесь», «Распаковать в...», «Открыть в Raspak», «Проверить архив». В Windows 11 - в новом меню (подменю «Raspak»), в Windows 10 и в «Показать дополнительные параметры» - в классическом.
- **Пачкой.** Выделили 20 архивов и нажали «Распаковать здесь» - одно окно прогресса на все.
- **Многотомные архивы.** Какой том ни открой, распаковка идет с первого, а выделенные вместе тома одного набора распаковываются один раз. Raspak проверяет, что все тома на месте, и предупреждает о недокачанных (`.part`, `.crdownload`, `.!qB` и т. п.).
- **Защита от вредных архивов.** Пути `..\..\` и `C:\...` не выходят за папку распаковки, ссылки не создаются, имена `CON`, `aux.txt` и символы `<>:"|?*` исправляются.
- **Упаковка.** Правая кнопка на файле или папке: «Добавить в «Имя.zip»» сразу или «Добавить в архив...» с маленьким окном (имя, ZIP / 7Z / TAR.GZ / TAR.ZST, сжатие, пароль AES-256 для zip). Окно сразу показывает примерный размер архива. Уровень «Ультра» для 7z и tar.zst - большое окно сжатия, находит повторы между файлами.
- **Добавление в архив.** Открыть архив, зайти в папку и перетащить туда файлы. ZIP дописывается без пересжатия старого (в zip с паролем новые файлы шифруются тем же паролем), tar и сжатые tar пересобираются тем же методом. 7z, rar и многотомные архивы не меняются. Архив подменяется только в конце: отмена или ошибка его не портят.
- **Самообновление** из релизов GitHub.

## Скорость

- zip распаковывается в несколько потоков: файлы в zip независимы.
- 7z: свой параллельный декодер LZMA2. Многопоточный 7-Zip режет поток на блоки со сбросом словаря, Raspak распаковывает их одновременно и отдает данные по мере готовности.
- rar и tar.*: распаковка в одном потоке, запись файлов параллельно с ней; gzip многопоточный.

Замер: 1500 файлов, 286 МБ, тот же диск, по три прогона:

| архив | Raspak | 7-Zip 24 (`7z x`) |
|---|---|---|
| zip (deflate) | 1,07-1,32 с | 1,16-1,18 с |
| 7z (LZMA2, многопоточный) | 1,5-1,9 с | 1,19-1,27 с |
| tar.gz | 1,16-1,32 с | - |

Упаковка тех же 286 МБ: zip - 0,11 с (7-Zip `a -tzip -mx5` - 0,9 с), tar.gz - 0,25 с, tar.zst - 0,36 с. zip сжимается на всех ядрах, уже сжатое (jpg, mp4, zip...) кладется без пересжатия.

## Меню Windows 11

Новое меню Windows 11 показывает только расширения из подписанных пакетов MSIX. Raspak делает такой пакет сам при включении пункта в настройках:

1. создает на компьютере самоподписанный сертификат `CN=Raspak Local`;
2. собирает пакет без файлов программы (sparse package: манифест, COM-сервер, картинки) и подписывает его;
3. удаляет закрытый ключ: больше этим сертификатом ничего не подписать;
4. добавляет сертификат в доверенные и регистрирует пакет для текущего пользователя. Если Windows не доверяет хранилищу пользователя, один раз просит права администратора.

Проводник читает меню при старте, поэтому после установки Raspak предлагает его перезапустить. При выключении пункта пакет и сертификат удаляются.

## Технологии

- **Go**, сборка с `CGO_ENABLED=0`.
- [lxn/walk](https://github.com/lxn/walk) - главное окно на родных элементах Windows; окно упаковки на WebView2 ([go-webview2](https://github.com/jchv/go-webview2)).
- [mholt/archives](https://github.com/mholt/archives), [bodgit/sevenzip](https://github.com/bodgit/sevenzip), [nwaples/rardecode](https://github.com/nwaples/rardecode), [yeka/zip](https://github.com/yeka/zip) - чтение архивов.
- [klauspost/compress](https://github.com/klauspost/compress), [pgzip](https://github.com/klauspost/pgzip), [ulikunitz/xz](https://github.com/ulikunitz/xz) - сжатие.
- Свой параллельный декодер LZMA2 и запись 7z.
- COM и MSIX (sparse package) Windows для меню Windows 11.

## Требования

Windows 10 или 11, x64.

## Как начать

Скачать `Raspak.exe` из [релизов](https://github.com/Trashfallen/Raspak/releases/latest) и запустить. При первом запуске Raspak спросит, встроиться ли в проводник. Настройки (шестеренка): меню проводника, открытие архивов двойным кликом, открывать ли папку после распаковки, проверка обновлений. Данные программы: `%APPDATA%\Raspak`.

Командная строка:

```bat
Raspak.exe archive.zip                 :: открыть в окне
Raspak.exe --extract a.zip b.rar       :: распаковать рядом
Raspak.exe --extract-to a.zip          :: спросить папку
Raspak.exe --test a.7z                 :: проверить
```

## Сборка

Нужен Go (версия в `go.mod`).

```
build.cmd        # dist\Raspak.exe
go test ./...
```
